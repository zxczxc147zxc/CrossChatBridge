# CrossChatBridge

**CrossChatBridge** 是一个轻量级的 Fabric 服务端模组，用于在多个 Minecraft 服务器之间实现跨服聊天消息同步。采用 TCP 协议连接，支持 HOST/CLIENT 模式，配置简单，开箱即用。

---

## 功能特点

- **跨服聊天同步**：将任意服务器的玩家聊天消息实时广播到所有已连接的子服。
- **双模式支持**：
  - **HOST 模式**：作为中心节点，接收客户端注册并统一转发消息。
  - **CLIENT 模式**：连接到指定的 HOST，发送本地消息并接收来自其他服务器的广播。
- **共享密钥认证**：通过配置统一的 `secret` 密钥（SHA-256 哈希）防止未授权连接，避免恶意伪造服务器名称。
- **热加载配置**：支持 `/crosschat reload` 命令动态重载配置并重置网络连接，无需重启服务器。
- **自动重连**：CLIENT 端与 HOST 断开连接后，会自动每隔 5 秒尝试重连，保证服务稳定性。
- **极简配置**：所有配置集中在单个 `config/crosschat.properties` 文件中，易于管理。

---

## 安装与使用

1. 将模组 JAR 文件放入所有需要互联的服务端的 `mods` 文件夹中。
2. 启动服务器，模组会自动生成默认配置文件 `config/crosschat.properties`。
3. 根据你的网络架构修改配置：
   - **指定一台服务器作为 HOST**：将其 `server.mode=HOST`。
   - **其余服务器作为 CLIENT**：将 `server.mode=CLIENT`，并配置 `host.ip` 和 `host.port` 指向 HOST 服务器。
   - **所有服务器必须使用相同的 `secret` 密钥**，否则连接将被拒绝。
4. 执行 `/crosschat reload` 重载配置，或直接重启服务器生效。

---

## 配置文件详解

配置文件位于 `config/crosschat.properties`，各字段说明如下：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `server.name` | 本服务器的名称，将作为消息前缀显示在聊天中 | `MyServer` |
| `server.mode` | 运行模式：`HOST` 或 `CLIENT` | `CLIENT` |
| `host.ip` | HOST 服务器的 IP 地址（CLIENT 模式使用） | `127.0.0.1` |
| `host.port` | HOST 服务器的监听端口（CLIENT 连接此端口） | `52134` |
| `host.listen_port` | HOST 实际绑定的本地端口（通常与 `host.port` 保持一致） | `52134` |
| `secret` | 共享密钥，所有服务器必须一致，用于身份验证 | `123456`（**请务必修改！**） |

> **提示**：
> - `server.name` 支持 Minecraft 颜色代码（如 `§cMyServer§r`），客户端会自动解析显示。
> - 如果你的 HOST 服务器有公网 IP 或使用端口映射，请确保 CLIENT 配置的 `host.ip` 和 `host.port` 能够正确访问到 HOST。

| 命令 | 权限 | 说明 |
|------|------|------|
| `/crosschat reload` | OP 级别 | 重新加载配置文件并重置网络连接（HOST 重启服务端，CLIENT 重新连接） |

## 工作原理

1. **启动阶段**：
   - **HOST** 启动 TCP 服务端，监听 `listen_port` 端口，等待 CLIENT 连接。
   - **CLIENT** 主动连接 HOST 的 `host.ip:host.port`。

2. **注册与认证**：
   - CLIENT 连接成功后，立即发送 `REGISTER` 数据包，包含本机 `server.name` 和 `secret` 的 SHA-256 哈希值。
   - HOST 验证哈希值是否与本地配置一致，通过则记录该连接，否则拒绝并关闭连接。

3. **消息流转**：
   - 任意服务器玩家发送聊天消息时，模组拦截并构造 `CHAT` 数据包。
   - **CLIENT** 将数据包发送给 HOST。
   - **HOST** 接收后，将消息封装为 `BROADCAST` 包，并转发给所有已注册的 CLIENT。
   - HOST 自身也会在本地显示该消息。
   - 所有收到广播的服务器在本地聊天栏显示格式化后的跨服消息。

---

## 消息格式说明

- **服务器名称前缀**：`server.name` 中的 `§` 颜色代码会被 Minecraft 客户端正常解析，你可以利用这一点让跨服消息前缀更醒目。
- **玩家消息内容**：仅同步纯文本内容，不保留玩家发送消息中的颜色、点击事件等富文本格式。

---

## 安全注意事项

- **共享密钥认证**：模组使用 `secret` 的 SHA-256 哈希进行注册验证，可以有效阻止未授权的连接尝试。**请务必修改默认的 `secret` 值**，避免被攻击者利用。
- **网络环境**：由于采用明文 TCP 传输，该模组**仅适用于可信的内网环境**。若在公网或不受信任的网络中部署，流量可能被窃听或篡改（属于网络层安全问题，非本模组可控）。
- **防火墙配置**：请确保 HOST 服务器的 `listen_port` 在防火墙中开放，且 CLIENT 能够正常访问该端口。

---

## 已知限制

- 仅同步玩家消息的纯文本内容，不保留颜色、点击事件等富文本格式。
- 不支持多级 HOST 层级结构（仅支持单 HOST 集中转发）。
- 若 HOST 服务器重启，所有 CLIENT 将断开并自动重连。
